# Design system y wireframes

**Origen:** secciones 97–111 del maestro v1.6.

## Principios

Rápido, cercano, confiable, local y escalable. Tokens iniciales de marca: verde `#00554E` y amarillo `#FEDA04`, sujetos a validación de identidad propia. Todo contraste debe cumplir WCAG AA y ningún estado depende solo del color.

## Foundations

- Tipografía propuesta: Inter con fallback `system-ui, Arial, sans-serif`.
- Escala: 12, 14, 16, 18, 20, 24, 32 y 40 px.
- Espaciado base 4 px; radios 8/12/16/pill.
- Touch target mínimo 44 × 44 px.
- Breakpoints: xs 0–479, sm 480–767, md 768–1023, lg 1024–1439, xl 1440+.

## Componentes

Navegación, acciones, formularios, datos, estados, overlays, commerce, logística, operación y feedback. Button, input, store/product/order cards, status chip, modal destructivo, timeline y data table requieren variantes y estados definidos.

## Wireframes

Cubren móvil cliente, tablet de tienda y desktop administrador. Son estructura/jerarquía, no acabado visual. El handoff futuro incluye foundations, componentes, patterns, pantallas, prototipo, anotaciones de API/permisos y checklist accesible.
